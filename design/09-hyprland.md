# 09 · Hyprland profile

All Lua here targets Hyprland 0.57.1's Lua API. Function and option names were checked against the
API stubs shipped with it (`/usr/share/hypr/stubs/hl.meta.lua`); names the stubs do not list
(window-rule effects, curve spring fields, dispatcher arguments) follow the shipped
`/usr/share/hypr/hyprland.lua` and are verified by probe P-03 before phase 2.

## 1. What changes in `hyprland.lua`

`~/.config/hypr/hyprland.lua` stays Lenno's own file. aptus never rewrites it silently:
`install.sh` shows this diff and applies it only after Lenno says yes, keeping a backup at
`~/.local/state/aptus/install/hyprland.lua.<date>`.

**Removed** (Noctalia-specific, dead in an aptus session):

| Lines | Why |
|---|---|
| `local noctalia = …`, `local menu = …`, `local lock = …` | only used by Noctalia binds |
| `hl.on("hyprland.start", function() hl.exec_cmd("noctalia") end)` | Noctalia must not run in Hyprland ([02](02-isolation.md) §8) |
| every `hl.bind` whose action calls `noctalia`, `menu` or `lock` (Super+D/Space/S/C/comma/X/L/T/N/W, Super+Shift+S, Print, XF86 audio/brightness/keyboard-light/media/Dictate/EmojiPicker/ScreenSaver) | replaced by aptus binds (§7) |
| `hl.bind(mainMod .. " + M", hl.dsp.exit())` | replaced by the graceful logout |

**Kept unchanged:** the header, monitors, `auto-workspace-monitors.sh`, `first_installed` and the
program locals, `XCURSOR_SIZE`/`HYPRCURSOR_SIZE`, permissions comments, look and feel (the aptus
block comes later and overrides what it sets), input (`kb_layout = "de"`), the 3-finger gesture,
the device example, all window and workspace binds, and both window rules.

**Added** at the very end:

```lua
-- >>> aptus >>>
-- aptus v2 (~/Code/Projekte/aptus). Managed by install.sh; `install.sh --uninstall` removes it.
require("aptus.init")
-- <<< aptus <<<
```

Even if a removed bind were left in place, nothing would fire twice: every aptus bind first calls
`hl.unbind` on its chord (§7).

Removing the block (uninstall) gives back plain Hyprland: no aptus look, motion, rules or binds.
The removed Noctalia lines are stored with their anchors in
`~/.local/state/aptus/install/removed.lua`; uninstall offers to put them back (diff, approval).

## 2. `~/.config/hypr/aptus/` (symlink to the repo's `hypr/`)

### `init.lua`

```lua
-- aptus: entry point, loaded from the marked block at the end of hyprland.lua
local home  = os.getenv("HOME")
local state = home .. "/.local/state/aptus/hypr/"

-- Generated values (colours, gaps, flags). Defaults keep Hyprland usable before the first render.
local gen = {
  ground = "rgb(191613)", line = "rgb(332d27)", accent = "rgb(9acfae)", shadow = "rgba(00000061)",
  frame_edge = 6, window_gap = 8, glass = false, reduce_motion = false,
}
local path = state .. "generated.lua"
local f = io.open(path, "r")
if f then
  f:close()
  local ok, t = pcall(dofile, path)
  if ok and type(t) == "table" then
    for k, v in pairs(t) do gen[k] = v end
  else
    hl.notification.create({ text = "aptus: generated.lua failed to load, using defaults", timeout = 8000 })
  end
end
package.loaded["aptus.gen"] = gen

require("aptus.env")
require("aptus.look")
require("aptus.motion")
require("aptus.rules")
require("aptus.binds")

hl.on("hyprland.start", function()
  hl.exec_cmd(home .. "/.local/bin/aptus-session start")
end)
```

## 5. `rules.lua`

```lua
local gen = require("aptus.gen")

-- Layers: the shell animates itself; Hyprland must not animate aptus layers.
hl.layer_rule({ name = "aptus-no-anim", match = { namespace = "^aptus-" }, no_anim = true })
hl.layer_rule({
  name = "aptus-glass", match = { namespace = "^aptus-shell$" },
  blur = true, ignore_alpha = 0.5, enabled = gen.glass,
})
hl.layer_rule({ name = "aptus-recframe", match = { namespace = "^aptus-recframe$" }, no_screen_share = true })

-- Windows
hl.window_rule({
  name = "aptus-settings", match = { class = "^aptus-settings$" },
  float = true, size = "920 640", center = true,
})
hl.window_rule({
  name = "aptus-scratch", match = { class = "^aptus\\.scratch$" },
  float = true, size = "monitor_w*0.7 monitor_h*0.6", move = "monitor_w*0.15 40",
})
hl.window_rule({
  name = "aptus-satty", match = { class = "^com\\.gabm\\.satty$" },
  float = true, size = "monitor_w*0.8 monitor_h*0.8", center = true,
})
hl.window_rule({
  name = "aptus-pip", match = { title = "^Picture-in-Picture$" },
  float = true, pin = true, keep_aspect_ratio = true,
  size = "480 270", move = "monitor_w-494 monitor_h-284",   -- 14 px inside the frame's corner
})
hl.window_rule({
  name = "aptus-portal-dialogs", match = { class = "^(xdg-desktop-portal-gtk|org\\.freedesktop\\.impl\\.portal\\..*)$" },
  float = true, center = true,
})
hl.window_rule({
  name = "aptus-idle-fullscreen", match = { class = ".*" },
  idle_inhibit = "fullscreen",
})

-- The scratch workspace starts its terminal on first use (a workspace.created handler: the
-- on_created_empty rule is deprecated in Hyprland 0.57)
hl.on("workspace.created", function(ws)
  if ws.name == "special:scratch" and ws.is_empty then hl.exec_cmd("ghostty --class=aptus.scratch") end
end)
```

`move` coordinates are relative to the monitor; 40 = bar 32 + gap 8, so the scratch terminal hangs
just below the bar. (P-03 confirms expression support in `size`/`move` and the effect names
`center`, `pin`, `keep_aspect_ratio`, `idle_inhibit`.)


Spring: ζ = damping / (2·√(stiffness·mass)) = 32.3 / 32.25 ≈ 1.0, no bounce (P-21 calibrates). The
shipped default config spells the field `damping`; Lenno's current file writes `dampening`, which
the aptus block does not depend on.

## 7. `binds.lua`

### Mechanism

```lua
local home = os.getenv("HOME")
local G = function(name) return hl.dsp.global("aptus:" .. name) end
-- Locking never fails open: `aptus msg` exits non-zero when the shell is down, frozen (2 s
-- timeout) or answers "error: …" (no lock screen yet); the aptus hyprlock.conf exists only after
-- the first theme render, so plain hyprlock is the last fallback.
local LOCK = home .. "/.local/bin/aptus msg session lock || hyprlock -c "
          .. home .. "/.local/state/aptus/hyprlock.conf || hyprlock"

-- Overrides from Settings › Keys: { [id] = "SUPER + J" | false }
local overrides = {}
do
  local p = home .. "/.local/state/aptus/hypr/binds.local.lua"
  local f = io.open(p, "r")
  if f then f:close(); local ok, t = pcall(dofile, p); if ok and type(t) == "table" then overrides = t end end
end

-- Description format read by the Binds service: "aptus:<id> | <Group> | <Description>[ | hidden]"
-- A chord is unbound only the first time aptus binds it in this load: `SUPER + Super_L` carries
-- two aptus binds (tap on release, hold on long press), and unbinding before the second would
-- delete the first (probe P-03).
local unbound = {}
local function bind(id, chord, action, group, desc, opts)
  local c = overrides[id]
  if c == false then return end
  c = c or chord
  if not unbound[c] then hl.unbind(c); unbound[c] = true end
  local o = {}
  for k, v in pairs(opts or {}) do o[k] = v end      -- L and R are shared; never mutate them
  o.description = "aptus:" .. id .. " | " .. group .. " | " .. desc
  hl.bind(c, action, o)
end
```

A description ending in `| hidden` keeps the row out of the Keys sheet (aliases such as
`Super+D`, and internal binds such as the switcher's Alt release).

Notes:
- The Super tap (`release`) and hold (`long_press`) are probe P-02: the tap must fire only when
  Super was pressed and released alone (not after `Super+drag` or a chord). Fallback: no tap;
  `Super+Space` stays.
- `ALT + Alt_L` with `release` is probe P-10 (Alt release reaches the shell while the switcher holds
  the keyboard). Fallback: the switcher commits on `Enter`/click and on a 1.2 s pause.
- Lenno's binds outside the block (terminal, browser, file manager, yazi, rotation, float, pseudo,
  split, fullscreen, focus arrows, workspaces 1–0, move to workspace, `Super+wheel`,
  `Super+Alt+←/→`, mouse move/resize) keep working unchanged. The Binds service describes them from
  `shell/config/known-binds.json` (dispatcher + argument patterns → group and description, e.g.
  `exec_cmd ghostty|kitty` → "Apps · Terminal", `focus workspace N` → "Workspaces · Go to N").

## 9. Runtime changes

| Change | How it reaches Hyprland |
|---|---|
| Accent, mode, glass alpha | `aptus-theme` rewrites `generated.lua`, then `hyprctl eval 'hl.config({ general = { col = { active_border = "rgb(94c3dc)", inactive_border = "rgb(332d27)" } }, misc = { background_color = "rgb(191613)" } })'` |
| `frame.edge` | same, with `gaps_out` |
| Glass on/off, reduced motion | `generated.lua`, then `hyprctl reload config-only` (rules and animations are declared, not patched) |
| Keys edited in Settings | `binds.local.lua`, then `hyprctl reload config-only` |
| Night light | `hyprctl hyprsunset temperature <K>` / `identity` |
| Lid closed with an external monitor (`power.lidDocked`) | `hyprctl eval 'hl.monitor({ output = "eDP-1", disabled = true })'`; on open, `hyprctl reload`, which re-applies Lenno's own monitor lines |
